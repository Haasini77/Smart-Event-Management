# EventHub – Smart Event Registration & Management System

EventHub is a full-stack web application for managing college events.

## Features

- User Registration and Login
- User Dashboard
- Create Events
- View Upcoming Events
- Register for Events
- View My Registered Events
- Cancel Event Registration
- Registration Capacity Management
- MongoDB Database

## Technologies Used

### Frontend
- React.js
- TypeScript
- CSS
- React Router

### Backend
- Node.js
- Express.js
- TypeScript
- JWT Authentication

### Database
- MongoDB
- Mongoose
